# Information Variance-Covariance Matrix for Confirmatory Factor Models

Information Variance-Covariance Matrix for Confirmatory Factor Models

## Usage

``` r
# S3 method for class 'lcfa'
information(fit)
```

## Arguments

- fit:

  A fitted object of class `"lcfa"`.

## Value

A list containing the CFA Hessian and variance-covariance matrix.
